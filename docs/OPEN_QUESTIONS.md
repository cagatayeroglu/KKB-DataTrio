# Organizer / Technical Open Questions

Ask/confirm as early as practical.

1. When will Kloudeks API credentials be distributed?
2. Which model IDs are available?
3. Does Kloudeks support native tool/function calling or guaranteed structured JSON output?
4. Are embeddings/rerankers exposed? Which models?
5. Rate limits, request/token limits, timeout limits?
6. Is internet/web access available to our application during the demo?
7. Are arbitrary external URLs allowed, or only organizer-approved sources?
8. Which file formats can hidden tests include?
9. Will the team receive a machine/GPU, or should the entire app run on our own machine?
10. Are coding assistants such as Codex/Claude Code allowed strictly during development, while runtime uses only Kloudeks?
11. Can organizer datasets be cached locally during the event/demo?
12. What exactly is persisted between demo questions/turns?
